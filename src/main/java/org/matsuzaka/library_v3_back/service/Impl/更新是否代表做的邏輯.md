```

if (dto.getRepresentative() != null && dto.getRepresentative()) {
```

這裡有兩個問題：
1.
null 和 false 的區別:
◦
dto.getRepresentative() == null: 這只處理了前端完全沒有傳 representative 欄位的情況。
◦
如果前端傳來的是 {"representative": false}，那麼 dto.getRepresentative() 會是 Boolean.FALSE，它不等於 null。因此，if (dto.getRepresentative() == null) 這個條件不會成立，book.setRepresentative(false) 也就永遠不會被執行。
2.
邏輯不互斥:
◦
if (dto.getRepresentative() != null && dto.getRepresentative()) 這個條件判斷的是 true 的情況。
◦
if (dto.getRepresentative() == null) 這個條件判斷的是 null 的情況。
◦
這兩個 if 是獨立的，沒有涵蓋 false 的情況，也沒有使用 else 來建立互斥關係。
正確的邏輯：
我們需要一個能同時處理 true, false, null 三種情況的完整邏輯。最清晰的寫法是使用 if-else if-else。
