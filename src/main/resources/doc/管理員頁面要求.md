
# 管理頁面前言
- 左邊選擇（盡量窄），右邊操作（很寬），根據左邊選擇切換右邊顯示
- 因資料顯示會很多，盡量少邊距
- 不需太多美化，簡潔方正即可
- 我為bookCopy新增欄位：stockedDate（進貨日）
- 書本的部分我已經有AdminBookController.java、AdminBookCopyController.java，先確認，基本上邏輯跟給使用者用的查詢一樣，所以要補上一些欄位和排序條件
- 其他視需求增加後端程式碼、API

## 借書
- **第一區**：兩個輸入框，cardId uniqueCode，cardId 有查詢按鈕，按了會先渲染第二區，uniqueCode 有送出按鈕，按了渲染第三區
- **第二區**：會員資訊，會員name、cardId、status、role、penalty_points、借閱數量 n/m
- **第三區**：本次借閱，共n本，再往下顯示書名、uniqueCode、借閱日期、到期日期，依據操作動態新增呈現，且動態渲染第二區的 借閱數量 n/m

## 還書
- **第一區**：uniqueCode 輸入框，有送出按鈕，按了會先渲染第二區
- **第二區**：會員資訊，會員name、cardId、status、role、借閱數量 n/m（先歸還，再渲染這區，所以初次成現實已經把這次歸還的變動算進去）
- **第三區**：本次歸還，共n本，再往下顯示書名、uniqueCode、借閱日期、到期日期，依據操作動態新增呈現，且動態渲染第二區的 借閱數量 n/m

## 書籍（一樣要有頁數，排序）
- **第一區**：各種查詢輸入筐，主類別（下拉選項，預設所有），次類別（下拉選項，需先選主類別才可選，會根據主類選擇只顯示該主類下的次類），出版年份（輸入），作者關鍵字（輸入），出版商關鍵字（輸入），書名關鍵字（輸入），ISBN精確搜尋（輸入），三顆按鈕（列出所有，執行搜尋，清除篩選），再一顆大按鈕於右上角（新增書籍）
- **第二區**：顯示查詢結果（預設先不查）ID、書名、系列、主分類、次分類、作者、出版年份、出版商、ISBN、是否代表作、上架日、借閱次數、在館狀況（n/m）、操作（編輯，刪除）、副本（查看副本）
    - 如果按了編輯，跳出浮動視窗，除ID外欄位皆可編輯（注意作者和標籤處理，因是多對多），有預覽和取消按鈕，預覽畫面有取消按鈕和送出按鈕
    - 如果按了刪除，會先跳警告是否確定刪除
    - 如果按了查看副本，就出現第三區
- **第三區**：BookId:N XXXX 的副本，顯示id、書籍碼、狀態、目前借閱者、借閱日、到期日、查看紀錄（借閱、預約）
    - 如果按了查看紀錄的借閱，跳出新分頁顯示借閱紀錄，同理按了預約就跳新分頁顯示預約紀錄
    - **借閱紀錄**：書名＋書籍碼在上，接著顯示loanId、card_id、renew_count、loan_date、due_date、return_date、status，由舊到新
    - **預約紀錄**：書名＋書籍碼在上，接著顯示reservationId、card_id、queue_position、reserve_date、notify_date、expiration_date、pickup_date、status，由舊到新
- **如果按了新增書籍**，跳出浮動視窗，其中主類別（輸入兼具下拉選項），次類別（輸入兼具下拉選項，需先選主類別才可選，會根據主類選擇只顯示該主類下的次類），作者（輸入兼具下拉選項，注意須支援多重輸入），出版商（輸入兼具下拉選項），系列（輸入兼具下拉選項），作者（輸入兼具下拉選項），標籤（輸入兼具下拉選項，注意須支援多重輸入），有預覽和取消按鈕，預覽畫面有取消按鈕和送出按鈕

## 分類
- **左區**：條列顯示所有主分類（id、category_title），旁有編輯刪除鈕，直接在這畫面編輯（原本編輯鈕變取消，且再多一個送出），刪除會先跳警告是否確定刪除。最後一條下方有個新增按鈕，按了一樣直接在這畫面編輯
- **右區**：依據主分類選擇，顯示所有子分類，操作邏輯同主分類

## 作者
- **第一區**：關鍵字搜尋（預設先不查），有按鈕（列出所有），再一顆大按鈕於右上角（新增）
- **第二區**：顯示搜尋結果，旁有編輯刪除鈕（如同分類處理方式）
- 如果按了新增，跳出浮動視窗
