# 預約功能說明

## 預約邏輯

### 核心概念
本系統的預約是針對**特定的書籍副本（BookCopy）**，而不是整本書（Book）。

### 預約條件

#### 1. 使用者條件
- 帳號狀態必須為 `ACTIVE`（已啟用）
- 預約數量限制：
  - 一般民眾（`ROLE_USER`）：最多 5 本
  - 台中市民（`ROLE_CITIZEN`）：最多 10 本
  - 管理員（`ROLE_ADMIN`）：最多 10 本

#### 2. 書籍副本條件
- **只有狀態為 `L`（Loaned，已借出）的副本才能預約**
- 不可預約的狀態：
  - `A`（Available，在館可借）：直接借閱即可，無需預約
  - `R`（Reserved，已被預約）：已被其他人預約
  - `P`（Processing，處理中）：正在處理，無法預約
  - `U`（Unavailable，下架）：已下架，無法借閱或預約

#### 3. 重複預約檢查
- 同一使用者不能重複預約同一個書籍副本

### 預約流程

```
1. 使用者選擇特定的書籍副本（BookCopy）
   ↓
2. 系統檢查：
   - 使用者狀態（必須是 ACTIVE）
   - 預約額度（是否已達上限）
   - 副本狀態（必須是 L）
   - 是否重複預約
   ↓
3. 計算排隊位置（依現有 PENDING 預約的最後位置 +1）
   ↓
4. 創建預約記錄（狀態：PENDING）
   ↓
5. 發送預約成功通知給使用者
```

### 預約狀態說明

| 狀態 | 說明 |
|------|------|
| `PENDING` | 等待中（排隊中） |
| `AVAILABLE` | 可取書（書已歸還，輪到此使用者） |
| `PICKED_UP` | 已取書（已完成借閱） |
| `EXPIRED` | 已過期（超過取書期限未取） |
| `CANCELLED` | 已取消 |

### 歸還後的預約處理

當書籍副本歸還時（`LoanService.returnBook`）：

```
1. 書籍歸還
   ↓
2. 呼叫 ReservationService.handleReturn(bookCopyId)
   ↓
3. 查找此副本的預約佇列（PENDING 狀態，按 queuePosition 排序）
   ↓
4. 如果佇列為空：
   - 副本狀態改為 A（可借閱）
   
5. 如果佇列有人：
   - 取出第一位預約者
   - 預約狀態改為 AVAILABLE
   - 設定通知日期為現在
   - 設定取書截止日期（通知日期 +7 天）
   - 副本狀態改為 R（已預約）
   - 發送通知給預約者
```

### 取書期限

- 使用者收到「可取書」通知後，有 **7 天**的時間到館取書
- 超過期限未取：
  - 預約狀態變為 `EXPIRED`
  - 系統通知下一位排隊者
  - 副本繼續保持 `R` 狀態，遞補給下一位

## API 端點

### 1. 預約書籍副本

**端點**：`POST /api/reservations/reserve`

**權限**：需登入

**請求體**：
```json
{
  "bookCopyId": 123
}
```

**成功回應**：
```json
"預約成功"
```

**錯誤回應範例**：
- `"使用者帳號未啟用，無法預約"`
- `"預約數量已達上限（5 本）"`
- `"此書籍副本目前無法預約（狀態：A）。只有已借出的書籍可以預約。"`
- `"您已預約此書籍副本"`

### 2. 取消預約

**端點**：`DELETE /api/reservations/{id}`

**權限**：需登入

**成功回應**：
```json
"取消預約成功"
```

### 3. 查看我的預約

**端點**：`GET /api/reservations/my`

**權限**：需登入

**回應範例**：
```json
[
  {
    "id": 1,
    "bookId": 100,
    "bookTitle": "哈利波特：神秘的魔法石",
    "imageUrl": "https://...",
    "bookCopyId": 123,
    "status": "PENDING",
    "queuePosition": 2,
    "reserveDate": "2024-12-01T10:00:00",
    "expirationDate": "2024-12-08"
  }
]
```

## 前端使用範例

### 預約按鈕邏輯

```javascript
// 檢查副本狀態，決定顯示按鈕
function getActionButton(bookCopy) {
  switch(bookCopy.status) {
    case 'A':
      return <button>立即借閱</button>;
    case 'L':
      return <button onClick={() => reserveBookCopy(bookCopy.id)}>
        預約此副本
      </button>;
    case 'R':
      return <span>已被預約</span>;
    case 'P':
      return <span>處理中</span>;
    case 'U':
      return <span>已下架</span>;
  }
}

// 預約函數
async function reserveBookCopy(bookCopyId) {
  try {
    const response = await axios.post('/api/reservations/reserve', {
      bookCopyId: bookCopyId
    });
    alert(response.data); // "預約成功"
  } catch (error) {
    alert(error.response.data); // 錯誤訊息
  }
}
```

## 通知說明

### 預約成功通知
- **類型**：`RESERVE_SUCCESS`
- **標題**：預約成功
- **內容**：您已成功預約《書名》（副本編號：XXX），目前排隊位置：第 N 位。書籍歸還後將依序通知取書。

### 書籍可取通知
- **類型**：`RESERVE_AVAILABLE`
- **標題**：預約書籍到館通知
- **內容**：您預約的書籍《書名》已到館，請於 YYYY-MM-DD 前取書。

### 預約過期通知
- **類型**：`RESERVE_EXPIRING`
- **標題**：預約已過期
- **內容**：您預約的《書名》已過期。

## 注意事項

1. **預約是針對特定副本**，不是整本書。同一本書可能有多個副本，使用者選擇哪個副本就預約哪個。

2. **只能預約已借出的副本**，在館可借的書直接借閱即可。

3. **排隊機制**：每個副本有獨立的預約佇列，按預約順序排隊。

4. **取書期限**：收到通知後 7 天內必須取書，否則預約失效。

5. **預約額度**：計算的是 `PENDING` 和 `AVAILABLE` 狀態的預約總數。

6. **管理員操作**：管理員透過輸入 `unique_code` 處理取書（將預約轉為借閱）。
