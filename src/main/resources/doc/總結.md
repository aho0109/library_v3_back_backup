6. **Tag** - 標籤

#### **使用者系統**
9. **User** - 使用者
    - 角色：`ROLE_USER`(一般), `ROLE_CITIZEN`(市民), `ROLE_ADMIN`(管理員)
    - 狀態：`PENDING`(待啟用), `ACTIVE`(正常), `SUSPENDED`(停權)

    - 欄位：queuePosition, reserveDate, notifyDate, expirationDate, pickupDate
    - 取書期限：7天

13. **Review** - 評論
    - 欄位：rating(1-5), reviewText, likesCount

14. **ReviewLike** - 評論按讚

15. **Notification** - 通知
    - 類型：`WELCOME`, `RESERVE_SUCCESS`, `RESERVE_AVAILABLE`, `RESERVE_EXPIRING`, `LOAN_DUE`, `PENALTY`
    - 欄位：type, title, content, isRead, referenceId, referenceType

16. **Favorite** - 收藏

## 🔥 核心業務邏輯實作

### **1. 預約系統**
```
流程：
1. 只能預約狀態為 L (已借出) 的副本
2. 檢查使用者額度（一般5本/市民10本）
3. 計算 queuePosition（排隊順位）
4. 創建 PENDING 狀態預約 → 發送通知

歸還處理：
1. 書籍歸還時，查找 PENDING 預約佇列
2. 若佇列為空 → 副本改為 A (可借閱)
3. 若有人預約 → 
   - 第一位改為 AVAILABLE
   - 副本改為 R (已預約)
   - 設定 expirationDate = 現在+7天
   - 發送可取書通知

取消預約：
- PENDING 取消 → 後面的人 queuePosition 往前遞補
- AVAILABLE 取消 → 呼叫 handleReturn 通知下一位
```

### **2. 借閱系統**
```
借書流程：
1. 管理員輸入 cardId + uniqueCode
2. 檢查：使用者狀態、借閱額度、副本狀態
3. 若副本為 R (已預約) → 檢查是否為此使用者的 AVAILABLE 預約
4. 創建 Loan (dueDate = +30天)
5. 副本改為 L，書籍 totalLoanCount++
6. 若有匹配預約 → 改為 PICKED_UP

還書流程：
1. 管理員輸入 uniqueCode
2. 檢查是否逾期 → 計算罰分
3. 罰分累積 ≥10 → 停權30天 + 罰分歸零
4. Loan 狀態改為 RETURNED
5. 呼叫 ReservationService.handleReturn() 處理預約佇列

續借規則：
- 最多續借2次，每次+10天
- 到期日前3天才可續借
- 有人預約則無法續借
```

### **3. 通知系統**
```
站內通知（已完成）：
- 儲存在 notification 表
- 每30秒輪詢未讀數量
- 支援標記已讀/全部已讀

觸發時機：
- RESERVE_SUCCESS → 預約成功/排隊更新
- RESERVE_AVAILABLE → 書籍可取書
- RESERVE_EXPIRING → 預約過期
- LOAN_DUE → 到期前3天
- PENALTY → 逾期/停權

Email 通知（TODO）：
- 預留介面，尚未實作
- 建議使用 Spring Mail 或 SendGrid
```

### **4. 排程任務**
```java
@Scheduled(cron = "0 0 0 * * ?") // 每天凌晨
public void dailyCheck() {
    // 1. 檢查逾期借閱
    - 每逾期1天 → +1罰分 + 發送通知
    - 罰分 ≥10 → 停權30天
    - Loan 狀態改為 OVERDUE
    
    // 2. 檢查預約過期
    - 找出 AVAILABLE 且過期的預約
    - 狀態改為 EXPIRED + 發送通知
    - 呼叫 handleReturn 遞補下一位
}
```

## 🔐 認證與權限

### **JWT Token**
- 登入後返回 Token（只返回 jwtToken，不返回 userId/role）
- Token 包含：userId, username, role
- 前端從 Token payload 解析 role

### **路由守衛**
```javascript
// 需登入
- /my
- 所有 /admin/** 路徑

// 需管理員
- /admin/** (檢查 isAdmin)
```

### **API 權限**
```java
@PreAuthorize("hasAuthority('ROLE_ADMIN')")  // 管理員
@PreAuthorize("isAuthenticated()")           // 需登入
```

## 🎯 設計核心

### **1. 預約系統的設計**
- 預約是針對**特定副本**，不是整本書
- 排隊機制：queuePosition 自動計算和遞補
- 歸還時自動通知下一位
- 過期自動遞補

### **2. 罰分與停權機制**
- 逾期1天 = 1罰分
- 累積10罰分 = 停權30天 + 罰分歸零
- 停權可疊加（suspendedUntil 基於已有停權時間）
- 停權自動解除檢查（借書時檢查）

### **3. 續借限制**
- 最多2次
- 到期前3天才開放
- 有人預約則禁止

### **4. 搜尋系統**
- **管理員** 有額外條件：作者關鍵字、出版商關鍵字、書名關鍵字、ISBN
- **使用者** 只有基本條件：keyword, 分類, 作者ID, 出版商ID, 標籤
- 搜尋結果回傳 `stats`（當前結果的統計，用於動態更新篩選器）

### **5. 前端優化**
- Axios 攔截器統一處理 Token 和錯誤
- Pinia Store 集中管理狀態
- URL 參數同步（搜尋條件、分頁）
- 樂觀 UI 更新（按讚功能）
- 每30秒輪詢未讀通知數量
